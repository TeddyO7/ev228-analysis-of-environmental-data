# ev228-analysis-of-environmental-data
Code for EV228: Analysis of Environmental Data at Colorado College.

## Code Index
Code is in the root directory. Unless otherwise specified, all code is in Python.
* `count_outcomes`: Count and display outcomes for a virtual dice roller
* `fun_probability`: functions relating to probability tasks
* `utensils_fun_demo`: utensils demonstration written in functions
* `utensils_script_demo`: utensils demonstration written as a script

## Reading Index
Readings are in the `reading` subdirectory. Unless otherwise specified, all readings are written in Markdown.
* creator-computer-literacy: Describes fundamental skills involved in the consumer to creator transition
* coding-ide-iterating-github: Explores writing code in an IDE and logging changes through GitHub
* setup-day: General script for setting up computers on Setup Day. (Not used in 2026; in preparation for future years.)
